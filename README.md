# Vàng Bạc Đức Thịnh

Website giới thiệu cửa hàng Vàng Bạc Đức Thịnh – 105A1 Nguyễn Quý Đức, Thanh Xuân, Hà Nội.

Xây dựng bằng **Vite + React + TypeScript**, deploy tự động lên **GitHub Pages** mỗi khi push lên nhánh `main`.

## Chạy local

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # build ra thư mục dist/
```

## Cấu trúc

- `src/App.tsx` – toàn bộ nội dung trang (dữ liệu sản phẩm, đánh giá… nằm ở đầu file)
- `src/index.css` – giao diện
- `public/images/` – hình ảnh (ảnh minh họa từ Unsplash)
